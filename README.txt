AUTOVERSE - Premium dark automotive discovery website

HOW TO USE
1. Extract this ZIP file on your computer.
2. Open your GitHub repository: https://github.com/milanbkofficial/autoverse
3. Remove or replace the old website files in the repository root.
4. Upload ALL files from this extracted folder directly into the repository root.
5. Keep all files together in the same root folder. Do not create an assets folder.
6. Commit the upload and wait for GitHub Pages to publish.

The website uses root-relative file names:
style.css, data.js, app.js, favicon.svg

Pages: Home, Explore, Compare, Brands, Categories, Performance, Popular, About.

Note: Example vehicle specifications and prices are illustrative starter data and may not be current. Verify details with manufacturers before relying on them.
